Everything for the page you are on, in one popup.

Open it with Alt+Shift+S. Each storage type has copy, paste, clear and details.

  • Finds the right token

    Looks through Local Storage, Session Storage and cookies, including tokens nested inside JSON. Refresh tokens and expired tokens are skipped. Pin a different source per site if you need to.

  • Raw or Bearer

    Copy the token as it is, or as Bearer <token> for an Authorization header.

  • Merge or Replace

    Pasting asks whether to keep existing keys or delete them first.

  • Snapshots

    Save a site's storage and cookies, then switch back with one click. Handy for moving between test users.

Right-click instead of opening anything.

The most common actions sit in the page's context menu. A short message on the page confirms what happened; clearing and restoring ask first.

  • Alt+Shift+T

    Copies the access token from anywhere on the page.

  • Paste from production into localhost

    Cookies copied from another domain are set on the current site, so a session can move between environments.

A details view that shows what is really stored.

Search, edit and delete keys. JWTs are decoded with their expiry. JSON is formatted. Pick an iframe to see its storage too.

Local and Session Storage: values as text or JSON, JWTs decoded with exp and iat, Copy as Bearer, Pin as access token.

Your tokens stay in your browser.

No server

StorageNinja has no backend, no analytics and no account. Nothing is sent anywhere.

No remote code

All code ships inside the extension. Nothing is downloaded at runtime.

You decide what leaves

Data leaves the extension only when you copy it or export a file. Snapshots are kept in Chrome's local extension storage.
